# Saihaan Digital Growth

Create a premium, modern, mobile-first website for my business called Saihaan Digit.

The purpose of this website is to convince local service businesses to hire me to redesign or build modern, professional websites that help them get more customers and generate more phone calls.

Target audience:

Small local businesses such as plumbers, electricians, HVAC companies, landscapers, roofers, painters, contractors, cleaners, auto detailers, tutors, dentists, physiotherapists, and other trades or service businesses.

Use excellent typography.

Create strong visual hierarchy.

Follow WCAG accessibility principles.

Follow psychological principles such as:

 Visual Hierarchy
